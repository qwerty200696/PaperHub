## 🧠 重构智慧

### 1. 渐进式重构
- **第一步**：先分离 CSS，JS 保持不动 ✅
- **第二步**：添加 `/src` 路由，修复 404 ✅
- **第三步**：拆分 API/Utils/Store 并行开发
- **第四步**：双版本兼容（现在就运行在这个阶段）

### 2. 向后兼容保证
```
index.html 完整内联版本（稳定运行）
      ↓ 可通过 ?modular=1 启用
src/js/app.js 模块化版本（测试开发）
```

### 3. Vue 3 最佳实践
采用 **组合式函数 (Composables)** 架构：
```javascript
// 旧：一个大的 setup() 返回 80 个变量
setup() { 80 个 ref 和 function }

// 新：按领域拆分
const paperStore = usePaperStore();
const ingestStore = useIngestStore();
return { ...paperStore, ...ingestStore };
```

## 🎯 架构收益

1. **新人上手快**：想看「筛选逻辑」→ 直接找 `usePaperStore.js`
2. **加功能不纠结**：「新增导出功能」→ 加在 `PaperAPI` + `usePaperStore`
3. **Bug 定位准**：「排序不对」→ 只看 `sortPapers()` 那 30 行
4. **单元测试易**：每个 Store 都是纯 JS，可独立测试
5. **代码复用高**：工具函数、API 调用随处引用
