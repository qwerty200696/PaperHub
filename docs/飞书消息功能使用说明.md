# 飞书消息功能使用说明

## 功能概述

PaperHub 集成了飞书消息功能，支持：
- 🔍 搜索和浏览飞书群聊列表
- 📨 拉取群聊历史消息（支持分页加载更多）
- 💾 离线缓存消息到本地
- 📂 查看和管理离线消息

## 前置准备

### 1. 安装 lark-cli

```bash
npm install -g @larksuite/lark-cli
```

### 2. 配置飞书应用（可选）

有两种使用方式：

#### 方式一：使用 User 身份（推荐，简单）

1. 在终端运行授权命令：
```bash
lark-cli auth login --scope "im:chat:read,im:message:readonly"
```

2. 按照提示完成浏览器授权

3. 在 PaperHub 飞书消息页面**不需要填写** App ID 和 App Secret

#### 方式二：使用 Bot 身份

1. 在[飞书开放平台](https://open.feishu.cn/)创建应用
2. 开通以下权限：
   - `im:chat:read` - 读取群聊信息
   - `im:message:readonly` - 读取消息
3. 获取 App ID 和 App Secret
4. 在 PaperHub 飞书消息页面填写这两个配置

## 使用流程

### 1. 获取群聊列表

1. 打开 PaperHub 工具箱 → 飞书消息
2. （可选）在搜索框输入关键词筛选群聊
3. 点击「📥 获取群列表」按钮
4. 如果群聊较多，可以点击「加载更多群聊」

### 2. 查看群聊消息

1. 从下拉列表选择一个群聊
2. 点击「📤 拉取最新消息」获取最近50条消息
3. 如果有更多消息，点击「⬇️ 加载更多」继续加载
4. 可以通过右上角的下拉框调整显示数量（50/100/全部）

### 3. 保存到离线

1. 拉取消息后，点击「💾 保存到离线」
2. 消息会缓存到 `data/feishu_messages/` 目录
3. 下次可以离线查看这些消息

### 4. 查看离线消息

1. 点击「📂 查看离线消息」按钮
2. 在弹出的对话框中可以看到所有已缓存的群聊
3. 点击「查看」加载该群聊的离线消息
4. 点击「删除」可以清除缓存

## API 接口说明

### 获取群聊列表
```
POST /api/feishu/groups?sort_type=ByActiveTimeDesc&page_size=50&page_token=xxx
Body: { "appId": "...", "appSecret": "..." } (可选)
```

### 获取群消息
```
POST /api/feishu/messages
Body: {
  "chatId": "oc_xxx",
  "appId": "...",
  "appSecret": "...",
  "sort": "desc",
  "page_size": 50,
  "page_token": "xxx"
}
```

### 保存离线消息
```
POST /api/feishu/offline/save
Body: {
  "chatId": "oc_xxx",
  "chatName": "群聊名称",
  "messages": [...],
  "savedAt": "2026-05-28T10:00:00"
}
```

### 获取离线消息列表
```
GET /api/feishu/offline/list
```

### 加载离线消息
```
POST /api/feishu/offline/load?offset=0&limit=50
Body: { "chatId": "oc_xxx" }
```

### 删除离线消息
```
POST /api/feishu/offline/delete
Body: { "chatId": "oc_xxx" }
```

## 注意事项

1. **权限要求**：确保飞书应用或用户账号有读取群聊和消息的权限
2. **消息限制**：每次最多获取50条消息，需要多次加载才能获取全部历史
3. **离线存储**：离线消息存储在 `data/feishu_messages/` 目录，以 JSON 格式保存
4. **演示模式**：如果未配置 API 且获取失败，会自动使用演示数据
5. **Bot 身份限制**：使用 Bot 身份时，只能访问机器人所在的群聊

## 常见问题

### Q: 获取群列表失败？
A: 检查是否已完成 `lark-cli auth login` 授权，或检查 App ID/Secret 是否正确

### Q: 看不到某些群聊？
A: 确保你的账号或机器人是该群聊的成员

### Q: 消息内容显示不完整？
A: 富文本消息可能只显示部分格式，图片和文件会显示为占位符

### Q: 如何清理离线缓存？
A: 在「查看离线消息」对话框中点击删除，或直接删除 `data/feishu_messages/` 目录下的文件

## 技术实现

- 后端：Flask API + lark-cli 命令行工具
- 前端：Vue 3 + Element Plus
- 存储：localStorage（配置）+ JSON 文件（离线消息）
