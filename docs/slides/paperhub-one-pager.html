目标用户
算法工程师

PaperHub 是一个本地优先的知识管理系统，解决算法工程师在论文阅读、文章收藏和笔记整理中的碎片化问题。所有数据存储在本地 SQLite，支持 arXiv 论文自动抓取、微信公众号/知乎文章导入、AI 对话笔记沉淀，以及 AI 一键解读论文。三大模块（论文库 / 文章库 / 笔记库）采用统一架构设计，一次学习，处处通用。

核心能力

覆盖知识管理全链路，从入库、整理到检索、输出。

  • 多源入库：arXiv 论文 / 微信文章 / 知乎专栏 / 通用网页 / 对话笔记
  • 智能处理：PDF 解析、HTML 本地化、图片防盗链解决、去重检测
  • AI 集成：论文 AI 解读、多提供商支持（豆包 / OpenAI / 千问 / Claude）
  • 全文检索：SQLite FTS5 实现，300ms 防抖 + 键盘导航

产品亮点

以「一致性」为黄金原则，降低用户学习成本。

  • 三库统一：90% 交互逻辑复用，状态 / 标签 / 排序完全一致
  • 阅读状态：待读 / 在读 / 已读 / 精读，视觉化区分
  • 标签同步：笔记一键同步关联论文/文章的所有标签
  • 批量操作：批量删除 / 打标签 / 改状态，效率提升
设计方法论：「论文库有的，文章库、笔记库也要原封不动抄过去，用户只学习一次！」—— 三库 100% 布局一致、交互一致、CSS 类一致，是 PaperHub 最核心的架构决策。
