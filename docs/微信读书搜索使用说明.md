# 微信读书搜索使用说明

## 功能概述

PaperHub 集成了微信读书搜索功能，支持：
- 🔍 搜索微信读书中的书籍
- 📖 查看书籍详情、优质书评和热门划线
- 🎨 一键生成精美分享卡片
- 📤 导出划线/书评内容

## 前置准备

### 1. 安装 weread-skills

```bash
npx skills add weread-skills -g
```

### 2. 获取 API Key

1. 打开 PaperHub 工具箱 → 微信读书搜索
2. 点击 API Key 区域的 **"🔗 获取 SKILL APIKEY"** 按钮
3. 按照 weread-skills 的指引完成授权
4. 复制生成的 API Key
5. 粘贴到 PaperHub 的 API Key 输入框，点击保存

> 💡 API Key 保存在浏览器 localStorage 中，刷新页面后仍然有效

## 使用流程

### 1. 搜索书籍

1. 在搜索框输入书名、作者或关键词
2. 点击「搜索」按钮或按 Enter
3. 查看搜索结果列表

### 2. 查看书籍详情

1. 点击搜索结果中的书籍卡片
2. 进入详情页，展示：
   - 📚 书籍封面、标题、作者
   - ⭐ 评分、阅读量
   - 📝 优质书评（支持展开/收起）
   - 🔥 热门划线（金句）和读者想法

### 3. 生成分享卡片

1. 在书评或划线卡片上点击 **"📤 分享"** 按钮
2. 在弹出的编辑器中：
   - 选择布局（3种预设布局）
   - 自定义背景色
   - 编辑文字内容
3. 左侧实时预览分享卡片效果
4. 右键点击预览图即可保存为图片

## 注意事项

1. **API Key 有效期**：如遇到搜索失败，可能需要重新获取 API Key
2. **搜索范围**：只能搜索微信读书平台上有公开数据的书籍
3. **分享图片**：生成的分享卡片可直接保存为 PNG 图片，适合发朋友圈/小红书

## 常见问题

### Q: 搜索无结果？
A: 检查 API Key 是否配置正确，或尝试更换关键词

### Q: 分享卡片无法保存？
A: 右键点击预览区域的图片，选择"图片另存为"

### Q: API Key 失效？
A: 点击"🔗 获取 SKILL APIKEY"重新授权获取
