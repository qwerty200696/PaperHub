# 入库界面重构设计文档

## 📋 当前状态

### 现有 Tab 结构（2026-05-12）
1. **arXiv 入库** - ID输入 + 关键词搜索
2. **微信公众号** - 单篇导入 + 订阅管理
3. **知乎** - URL自动导入 + 手动粘贴
4. **🌐 通用网页** - 通用网页URL提取
5. **批量PDF/HTML上传** - 文件上传
6. **对话笔记** - 手动创建笔记
7. **💾 备份/恢复** - 备份恢复功能

### 问题
- Tab 太多（7个），分类不清晰
- 混杂了论文、文章、笔记、系统工具等多种类型功能
- 不利于后续扩展

---

## 🎯 重构方案

### 设计原则
- **按内容类型分类**（📚 论文 / 📰 文章 / 📝 笔记 / 💾 系统工具）
- **一级分类：2x2 大卡片网格**
- **二级分类：每个大卡片内纵向排列子功能卡片**
- **扩展性良好**：每个分类下可轻松添加新功能
- **点击交互**：点击子功能卡片 → 显示操作界面，有返回按钮

## 🎨 UI/UX 交互设计

### 页面层级
```
入库管理首页 (四宫格)
    ↓ 点击子功能卡片
功能操作界面 (带返回按钮)
```

### 视觉设计要点
1. **大卡片风格**：每个分类一个大卡片，有背景色区分
2. **子功能卡片**：浅灰色背景，悬停高亮，点击有反馈
3. **返回导航**：功能页面顶部有「← 返回入库首页」按钮
4. **待实现标记**：未实现功能显示「(开发中)」或「Coming Soon」

### 主要改动

#### 1. 状态管理
新增状态变量：
```javascript
const activeIngestView = ref('home'); // 'home' | 'arxiv' | 'wechat' | ...
```

新增函数：
- `switchIngestView(viewName)` - 切换到对应功能
- `goBackToIngestHome()` - 返回入库首页
- `handleComingSoon(featureName)` - 处理未实现功能提示
- 修复 `showIngest()` - 进入入库页面时自动返回首页

#### 2. UI 结构
- 移除原有 `el-tabs` 组件
- 新增「四宫格首页」（`activeIngestView === 'home'`）
- 所有功能视图保持原有代码，只添加了 `v-if="activeIngestView === 'xxx'"`
- 每个功能视图顶部添加「返回入库首页」按钮

#### 3. 新增样式
```css
/* 四宫格布局 */
```

### 遇到的问题与解决方案

| 问题 | 解决方案 |
|------|---------|
| **Div 标签不平衡** | 写 Python 脚本验证 `<div>` 数量匹配，逐个补全闭合标签 |
| **Vue 编译器错误 30** | 修复 `<template v-if>` + `v-else-if` 的组合，拆成独立链 |
| **首页不显示** | 修复 `showIngest()` 函数，添加 `activeIngestView.value = 'home'` |
