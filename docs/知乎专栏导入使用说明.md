## 方式一：URL 自动导入（推荐）

✅ **全自动，只需粘贴链接 + Cookie**

### 支持的链接格式

| 类型 | 示例 | 支持 |
|------|------|------|
| 知乎专栏 | `https://zhuanlan.zhihu.com/p/2031101471563962191` | ✅ |
| 知乎回答 | `https://www.zhihu.com/question/xxx/answer/2033140537973286819` | ✅ |
| 知乎文章短链 | `https://zhuanlan.zhihu.com/p/xxx` | ✅ |

---

### 获取 Cookie 详细步骤

> 💡 **只需配置一次，永久自动填充！**

#### Chrome / Edge 浏览器

1. **打开知乎并登录**
   - 访问 https://www.zhihu.com
   - 登录你的知乎账号

2. **打开开发者工具**
   - 按 `F12` 或 `Ctrl+Shift+I`（Mac: `Cmd+Opt+I`）
   - 切换到 **Application** (Chrome) / **存储** (Edge) 标签页

3. **找到 Cookies**
   ```
   Application → Storage → Cookies → https://www.zhihu.com
   ```

4. **全选复制所有 Cookie**
   - 点击 Cookie 列表中的任意一行
   - 按 `Ctrl+A` 全选
   - 按 `Ctrl+C` 复制

5. **正确的 Cookie 格式**
   ```
   _zap=xxx; _xsrf=xxx; d_c0=xxx; z_c0=xxx; ...
   ```

### 使用流程

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 切换到「知乎」入库标签页 | 默认就是「URL 自动导入」模式 |
| 2 | 粘贴知乎文章链接 | 专栏或回答链接均可 |
| 3 | 粘贴 Cookie | **第一次需要粘贴，之后自动填充** |
| 4 | 点击「自动解析并入库」 | ✅ 自动完成：抓取 → 解析 → 渲染 → 入库 |

> ✨ **Cookie 自动记忆**：第一次粘贴后，浏览器会永久保存，之后只需填 URL 即可！

## 方式二：手动粘贴内容

📝 **不需要 Cookie，兼容性最强**

### 使用场景

- Cookie 过期了暂时不想更新
- 知乎反爬临时加强 URL 方式失效
- 需要导入部分内容而非整篇文章

### 使用流程

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 切换到「📝 手动粘贴」模式 | 顶部单选按钮 |
| 2 | 浏览器打开知乎文章 | 找到你要导入的文章 |
| 3 | 全选内容 `Ctrl+A` | 包含标题、图片、代码、公式 |
| 4 | 复制粘贴到正文框 | 支持 Markdown 格式 |
| 5 | 补充标题、作者、日期 | 标题也可以留空，自动从正文提取 |
| 6 | 点击「导入知乎文章」 | 完成！ |

## Cookie 常见问题

### ❓ Cookie 会过期吗？

会！知乎 Cookie 有效期约 **1-2 周**，失效后重新获取即可。

**失效表现**：导入时提示「403 禁止访问」

**解决方法**：按照「获取 Cookie 详细步骤」重新复制粘贴一次。

---

### ❓ Cookie 会泄露隐私吗？

✅ **绝对安全！**

- Cookie **只存在你的本地浏览器**（localStorage）
- Cookie **只发送给知乎官网**（api.zhihu.com）
- PaperHub 服务器 **不存储** 你的 Cookie
- 全程在本地操作，无第三方服务

---

### ❓ 为什么必须要 Cookie？

知乎有非常严格的 **ZSE-CK 反爬虫系统**：
- 不带 Cookie 请求直接返回 403
- 即使带了 Cookie，还要验证十几种浏览器指纹
- 没有 Cookie = 100% 被反爬拦截

这就是为什么目前几乎所有知乎爬虫都失效了。

## 常见错误排查

| 错误提示 | 原因 | 解决方案 |
|---------|------|---------|
| **403 禁止访问** | Cookie 过期或无效 | 按教程重新获取 Cookie |
| **404 链接不存在** | URL 输入错误 | 检查链接格式是否正确 |
| **未找到正文内容** | Cookie 缺少关键字段 | 确保全选复制了所有 Cookie |
| **导入失败，请检查 Cookie** | Cookie 格式错误 | 不要手动修改 Cookie 内容，直接全选复制 |
| **图片加载失败** | 图片防盗链 | 属于正常现象，文章文本已完整保存 |

## 文件存储格式

每篇知乎文章会保存两个文件：

```
data/papers/zhihu/
├── zhihu_abc123def456.html    # 精美渲染的 HTML 预览文件
└── zhihu_abc123def456.md      # 纯净 Markdown 源文件
```

### HTML 文件特性

- 知乎专属蓝色主题 `#0084ff`
- 自动提取作者、发布时间
- 和微信公众号文章一致的阅读体验
- 支持代码高亮、公式、表格渲染

## 🔧 备选工具：脚本自动获取 Cookie

如果嫌 F12 手动复制麻烦，可以使用 PaperHub 提供的自动化脚本：

```bash
cd PaperHub
python3 tools/zhihu_cookie_get.py
```

### 脚本工作原理

| 步骤 | 说明 |
|------|------|
| 1 | 自动弹出一个独立的 Chrome 调试窗口 |
| 2 | 用户在窗口中手动登录知乎 |
| 3 | Chrome DevTools Protocol 自动抓取 Cookie |
| 4 | 自动输出格式化好的 Cookie 字符串 |
| 5 | 粘贴到入库界面的 Cookie 框即可 |

> ⚠️ **注意**：脚本方式需要关闭所有 Chrome 窗口才能运行，不如 F12 手动方式便捷。**推荐优先使用手动复制方式**。

---

## 💡 小技巧

1. **优先使用 URL 模式** - 全自动最省心
2. **导入成功一次后** - Cookie 就记住了，之后一劳永逸
3. **Cookie 失效提示出现时** - 花 30 秒重新复制就行
4. **紧急情况用手动模式** - 绕过一切反爬问题
5. **备选方案** - `tools/zhihu_cookie_get.py` 脚本自动获取
