# 数据导出功能说明

## 功能概述

PaperHub 支持将论文、文章和笔记数据导出为三种常用格式：
- **JSON** - 完整的数据结构，适合程序处理和备份
- **CSV** - 表格格式，可在 Excel 中打开和分析
- **Markdown** - 文本格式，适合导入到笔记工具（如 Notion、Obsidian）

## 使用方法

### 1. 访问导出界面

在 PaperHub 前端界面中：
1. 点击左侧菜单的 "📥 入库"
2. 在系统工具卡片中，点击 "📤 数据导出"

### 2. 选择导出格式

#### JSON 导出
- **适用场景**：数据备份、程序处理、迁移到其他系统
- **包含内容**：
  - 完整的论文/文章/笔记数据
  - 标签信息
  - 元数据（创建时间、更新时间等）
  - 关系信息（论文与标签的关联等）

**选项**：
- 选择要导出的数据类型（论文、文章、笔记，可多选）

**请求示例**：
```json
{
  "types": ["papers", "articles", "notes"],
  "include_tags": true,
  "include_content": true
}
```

#### CSV 导出
- **适用场景**：数据分析、Excel 处理、统计报表
- **包含内容**：
  - 表格化的数据结构
  - 主要字段信息

**选项**：
- 选择数据类型（论文、文章或笔记，单选）
- 每次只能导出一种类型

**请求示例**：
```json
{
  "type": "papers"
}
```

**默认导出字段**：
- 论文：`id`, `title`, `authors`, `abstract`, `source`, `category_l1`, `category_l2`, `status`, `starred`, `published_at`, `created_at`
- 文章：`id`, `title`, `author`, `source`, `url`, `status`, `starred`, `published_at`, `created_at`
- 笔记：`id`, `title`, `source`, `url`, `status`, `starred`, `pinned`, `created_at`, `updated_at`

#### Markdown 导出
- **适用场景**：导入到笔记工具、文档归档、分享
- **包含内容**：
  - 格式化的 Markdown 文档
  - 标题、作者、摘要、链接等信息
  - 标签信息

**选项**：
- 选择要导出的数据类型（可多选）
- 文件组织方式：
  - **单个文件**：所有内容在一个 Markdown 文件中
  - **分离文件 (ZIP)**：每种类型一个 Markdown 文件，打包为 ZIP，并附带 README.md

**请求示例**：
```json
{
  "types": ["papers", "articles", "notes"],
  "separate_files": false
}
```

### 3. 开始导出

1. 配置好导出选项后，点击 "开始导出"
2. 浏览器会自动下载生成的文件
3. 文件名格式：
   - JSON：`paperhub_export_YYYYMMDD_HHMMSS.json`
   - CSV：`paperhub_{type}_YYYYMMDD_HHMMSS.csv`
   - Markdown 单文件：`paperhub_export_YYYYMMDD_HHMMSS.md`
   - Markdown ZIP：`paperhub_markdown_YYYYMMDD_HHMMSS.zip`

## API 接口

### JSON 导出
```
POST /api/export/json
Content-Type: application/json

{
  "types": ["papers", "articles", "notes"],  // 要导出的数据类型
  "include_tags": true,                       // 是否包含标签信息
  "include_content": true                     // 是否包含完整内容
}
```

**响应**：JSON 文件下载（`application/json`）

### CSV 导出
```
POST /api/export/csv
Content-Type: application/json

{
  "type": "papers",                           // 要导出的数据类型: papers | articles | notes
  "fields": ["title", "authors", "abstract"]  // 可选，自定义导出字段
}
```

**响应**：CSV 文件下载（`text/csv; charset=utf-8-sig`）

### Markdown 导出
```
POST /api/export/markdown
Content-Type: application/json

{
  "types": ["papers", "articles", "notes"],  // 要导出的数据类型
  "separate_files": false                     // true = ZIP, false = 单个文件
}
```

**响应**：Markdown 文件或 ZIP 文件下载

## 错误处理

| HTTP 状态码 | 错误场景 | 前端提示 |
|-----------|---------|---------|
| 404 | 没有数据可导出 | "没有数据可导出" |
| 400 | 不支持的导出类型 | "不支持的导出类型: xxx" |
| 500 | 服务器内部错误 | "导出失败: {错误信息}" |

前端使用 `validateStatus` 捕获 4xx 错误并解析 JSON 错误响应，避免 blob 类型导致错误信息无法读取。

## 注意事项

1. **大数据量导出**：如果数据量很大，导出可能需要一些时间，请耐心等待
2. **浏览器兼容性**：建议使用现代浏览器（Chrome、Firefox、Safari、Edge）
3. **文件编码**：
   - JSON 和 Markdown 使用 UTF-8 编码
   - CSV 使用 UTF-8-BOM 编码（确保 Excel 正确显示中文）
4. **隐私安全**：导出的文件包含您的所有数据，请妥善保管
5. **临时文件清理**：后端使用 `response.call_on_close` 确保临时文件在响应发送后自动删除

## 技术实现

### 后端
- **文件**：`backend/api/export.py`
- **框架**：Flask Blueprint
- **依赖**：标准库（json, csv, zipfile, tempfile, os）
- **关键优化**：
  - 临时文件通过 `call_on_close` 自动清理，防止磁盘泄漏
  - 空数据检查，避免导出空文件
  - CSV 使用 `utf-8-sig` 编码，兼容 Excel 中文显示
  - Markdown ZIP 导出附带 README.md 说明文件

### 前端
- **文件**：`frontend/index.html`
- **框架**：Vue 3 + Element Plus
- **功能**：
  - 导出对话框（`el-dialog`）
  - 三种格式的独立选项配置
  - 文件下载处理（Blob + ObjectURL）
  - 错误处理（4xx 状态码解析）

## 未来优化方向
