# PaperHub 笔记与文章系统设计方案

---

## 一、设计理念

PaperHub 采用**三层内容库**架构：

| 内容类型 | 存储位置 | 说明 |
|---------|---------|------|
| 学术内容 | 论文库 (Paper) | arXiv、PDF 等学术论文 |
| 网络文章 | 文章库 (Article) | 微信公众号、知乎等网络文章 |
| 个人笔记 | 笔记库 (Note) | 个人对话记录、学习笔记 |

**关联关系**：
- 笔记 (Note) ↔ 论文 (Paper)：多对多
- 文章 (Article) ↔ 论文 (Paper)：多对多
- 笔记 (Note) ↔ 文章 (Article)：多对多（2026.5.2 新增）
- 三大模块各自独立的标签系统（2026.5.2 升级）

## 三、三大模块 标签系统（2026.5.2 重大升级）

### 3.1 设计原则：独立但复用

| 模块 | 标签筛选位置 | 标签数据来源 |
|------|-----------|------------|
| 📚 论文库 | 左侧边栏「阅读状态」下方 | /api/tags + paper_count 过滤 |
| 📰 文章库 | 左侧边栏「阅读状态」下方 | /api/tags + article_count 前端统计过滤 |
| 📝 笔记库 | 左侧边栏「笔记状态」下方 | /api/tags + note_count 前端统计过滤 |

### 3.2 标签筛选实现架构

```
/api/tags (统一返回所有标签)
        ↓
[前端按模块统计关联数]
        ├─ paper_count: 统计每个标签关联的论文数
        ├─ article_count: 统计每个标签关联的文章数
        └─ note_count: 统计每个标签关联的笔记数
        ↓
[各自过滤只显示有计数的标签]
```

### 3.3 智能同步标签功能（2026.5.2 新增）

**笔记详情页「🔄 同步关联标签」按钮**

**工作流：**
```
点击同步按钮
    ↓
收集关联论文的所有标签
收集关联文章的所有标签
    ↓
去重（排除笔记已有标签）
    ↓
批量自动添加到笔记
    ↓
提示：已同步 N 个标签: Agent, LLM, ...
```

**关键代码实现（models/paper.py 序列化层）：**
```python
# Note.to_dict() 序列化 papers/articles 时递归包含 tags
def to_dict(self, include_papers=False, include_articles=False, include_tags=True):
    if include_papers:
        result['papers'] = [p.to_dict(include_tags=True) for p in self.papers]
    if include_articles:
        result['articles'] = [a.to_dict(include_tags=True) for a in self.articles]
```
