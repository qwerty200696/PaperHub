# PaperHub Frontend Backups

此目录存放前端主文件 `index.html` 的历史备份。

---

## 备份命名规则

```
index.html.backup.v{版本号}_{日期}_{时间}
```

| 字段 | 说明 | 示例 |
|------|------|------|
| `v{版本号}` | 版本号，从 v1 开始递增 | v4 |
| `{日期}` | 备份日期，格式 YYYYMMDD | 20260505 |
| `{时间}` | 备份时间，格式 HHMMSS | 214146 |

## 备份时机

备份通常在以下时机创建：

1. ✅ **重大功能上线前** - 如 AI 解读功能、论文编辑功能
2. ✅ **架构变更前** - 如模块化重构、代码重构
3. ✅ **问题修复前** - 如 Bug 修复、性能优化

---

## 恢复方法

```bash
# 恢复到指定版本
cp backups/index.html.backup.v4_20260505_214146 index.html

# 启动服务测试
python -m http.server 8080
```

---

## 清理策略

- 保留最近 5 个备份
- 定期清理超过 3 个月的旧备份
- 清理前确认不再需要
