## ✨ 2026.5.2 重大升级：三大模块统一架构

| 模块 | 状态系统 | 标签系统 | 渲染方式 |
|------|---------|---------|---------|
| 📚 **论文库** | ✅ 4种阅读状态 | ✅ 独立标签筛选 | PDF 原生渲染 |
| 📰 **文章库** | ✅ 4种阅读状态 | ✅ 独立标签筛选 | iframe HTML 渲染 |
| 📝 **笔记库** | ✅ 4种笔记状态 | ✅ 独立标签筛选 | Markdown 完整渲染 |

### 🎯 核心亮点

1. **一致性原则** - 三模块 90% 交互逻辑复用，用户学习一次就够了
2. **智能同步标签** - 笔记一键同步关联论文/文章的所有标签
3. **Markdown 渲染** - 笔记正文支持完整的 Markdown 语法
4. **布局优化** - 笔记详情页：**内容优先展示**，关联信息后置

---

## 核心理念

- 📦 **本地优先** - 所有数据存储在本地，隐私安全，永久可用
- 🔌 **多源接入** - arXiv 论文 / 微信公众号 / AI 对话笔记 / 知乎专栏 一键入库
- 💬 **对话即知识** - 大模型对话也可以沉淀为知识库
- 🏷️ **三大模块独立标签** - 论文/文章/笔记 各自标签筛选，互不干扰
- 🔍 **多维筛选** - 状态 / 标签 多维度组合筛选
- � **智能标签同步** - 关联论文/文章的标签自动同步到笔记
- 📝 **统一预览** - PDF / HTML / Markdown 统一展示

## 快速开始

### 安装依赖

```bash
cd PaperHub/backend
pip install -r requirements.txt
```

### 启动服务

```bash
# 在 backend 目录下
python app.py
```

然后在浏览器打开: **http://localhost:5000**

## 💡 设计方法论

### 🎯 "一致性" 黄金原则

> **论文库有的，文章库、笔记库也要原封不动抄过去，用户只学习一次！**

| 层面 | 统一标准 |
|------|---------|
| **视觉** | 左侧色条配色完全一致：待读绿/在读蓝/已读灰/精镀金 |
| **布局** | 侧边栏：状态筛选在上，标签筛选在下 |
| **数据** | 排序算法：标星 → 状态 → 时间 |
| **交互** | 标签点击效果：plain/dark 两种状态 |

### 💡 什么时候前端算，什么时候后端算？

| 场景 | 谁来算 | 为什么 |
|------|-------|-------|
| 数据量 < 1000 | ✅ 前端 | 快！不用写 API！不用跑迁移！ |
| 数据量 > 10000 | ✅ 后端 | 前端卡 |
| 需要权限校验 | ✅ 后端 | 安全 |
| 和前端展示数据一致 | ✅ 前端 | 没有一致性问题！ |
